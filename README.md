# לוח הנסיעות

מעקב תורנות נהיגה לשניים. אין קשר לאפליקציית הכושר.

## קבצים
- **`index.html`** — כל האפליקציה בקובץ אחד (React + Tailwind מ-CDN). דאבל-קליק פותח בדפדפן, צריך אינטרנט.
- **`פתח את האפליקציה.bat`** — קיצור לפתיחה בדפדפן.
- גרסה חיה ונוחה לנייד: https://claude.ai/artifact/5ighDhpb7dXWSeQazzTW5y

זוהי הגרסה היחידה. הקובץ כאן וה-artifact זהים ומתעדכנים יחד.

## התקנה בנייד
צריך להיות מחובר (מחובר = מחובר) לחשבון ה-Claude שלך בדפדפן הנייד, כי ה-artifact פרטי.

1. פותחים את הקישור למעלה **בדפדפן של הנייד** (לא באפליקציית Claude).
2. **אייפון (Safari):** כפתור השיתוף (הריבוע עם החץ למעלה) ← "הוספה למסך הבית".
3. **אנדרואיד (Chrome):** תפריט שלוש הנקודות ← "התקנת אפליקציה" או "הוספה למסך הבית".
4. אייקון "נ" בכחול-ברונזה יופיע על המסך הראשי, ופתיחה ממנו נפתחת במסך מלא בלי סרגל הדפדפן.

**מגבלה:** אין עבודה אופליין — צריך אינטרנט בכל פתיחה (האפליקציה טוענת React/Tailwind מ-CDN). אם ה-artifact יקבל בעתיד קישור חדש, ה"התקנה" הישנה על המסך עלולה להפסיק לעבוד ותצטרך התקנה מחדש.

## מה יש
- **מי הוציא יותר** — השוואה ראש-בראש: כמה נסיעות כל אחד נהג, ומי מאחור מול הרוטציה המוסכמת. אם מגדירים "עלות דלק לנסיעה" בהגדרות — מוצג גם בשקלים.
- **לוח שבועי / חודשי** — כל יום מציג אות של הנהג (מקווקו = צפוי לפי התוכנית, מלא = נרשם בפועל), גם בתצוגת החודש. נגיעה ביום פותחת אותו לעריכה (אני / שותף / טרמפ אחר / לא נסענו + הערה).
- **מסלול המאזן** — גרף שמראה איך המאזן השתנה יום אחרי יום. גוררים עליו כדי לראות כל יום, לחיצה בוחרת את היום בלוח. מתחתיו רשימת האירועים שיצרו את המאזן.
- **אישור שבוע בלחיצה** — כפתור "אשר X ימים לפי התוכנית" סוגר את כל הימים שעברו בבת אחת.
- **שיתוף סיכום** — טקסט מוכן להדבקה בוואטסאפ, כדי לא להתווכח.
- **ביטול** — כל שינוי/מחיקה מראה "ביטול" למשך כמה שניות.
- **גיבוי ושחזור** — הגדרות ← גיבוי ושחזור. מעתיק/מדביק את כל הנתונים כטקסט.
- **סגירת חשבון** — מאפס את נקודת ההתחלה של המאזן.
- מצב כהה; שמות הנהגים והרוטציה השבועית נערכים ב-⚙.

הנתונים נשמרים ב-localStorage של הדפדפן, במכשיר הזה בלבד. אין חשבון, אין סנכרון — לכן כדאי להעתיק גיבוי מדי פעם.
